Online Payment Fraud Detection

A classroom prototype that classifies online payment transactions as potentially genuine (0) or fraudulent (1). It uses six transaction features: amount, time, location change, recent transactions, device change and failed attempts.

Workflow: Generate sample data → select features → split train/test data → train Random Forest → evaluate → predict a new transaction.

Important: The project uses synthetic demonstration data. Its results are not evidence of real-world banking accuracy.
