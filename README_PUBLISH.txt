# Thajjumul — Developer Portfolio

This is a static portfolio website containing:
- `index.html` — portfolio homepage
- `assets/Thajumul_Resume.pdf` — resume
- `assets/Online_Payment_Fraud_Detection_Presentation.pptx` — project presentation
- `assets/Online_Payment_Fraud_Detection_Source_Code.zip` — original project source ZIP
- `project/` — extracted Python source, README and explanation notes

## Publish free with GitHub Pages
1. Create a new public repository on GitHub named `thajjumul.github.io`.
2. Extract this portfolio ZIP on your computer.
3. Upload all contents inside the extracted `thajjumul_portfolio` folder to the repository root (make sure `index.html` is at the root, not inside another folder).
4. Commit the files.
5. Open repository Settings → Pages.
6. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
7. Wait for GitHub Pages to publish. Your site URL will be `https://thajjumul.github.io/`.

The site is static and does not require a build step.
